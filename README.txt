KING STORE DISCORD BOT V2

A V2 permite configurar a loja pelo Discord, sem editar o código.

COMANDOS:
 /setup - abre configuração inicial
 /produto criar - cria produto
 /produto estoque - adiciona Keys/itens
 /produto listar - lista produtos
 /painel - publica a loja
 /pedidos - mostra pedidos
 /gerarkey - gera uma Key

FLUXO:
1. Convide o bot.
2. /setup
3. /produto criar
4. /produto estoque
5. /painel
6. Cliente clica Comprar.
7. Bot cria pedido privado.
8. Admin confirma pagamento e o item é enviado por DM.

IMPORTANTE:
O bot precisa ficar hospedado em algum lugar para funcionar 24/7. Não é possível um bot do Discord funcionar somente por ser adicionado ao servidor; o código precisa estar rodando em um servidor/serviço.
Esta versão usa confirmação manual de pagamento. Para PIX automático, é preciso integrar um gateway e webhook.
Nunca compartilhe o token do bot.
